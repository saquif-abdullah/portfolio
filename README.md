# Saquif Portfolio

Open `index.html` in a browser.

Before publishing:
1. Replace `YOUR_EMAIL@example.com`.
2. Replace the LinkedIn and GitHub placeholder URLs.
3. Optionally add a professional photo and project screenshots.
4. Deploy the folder to GitHub Pages, Cloudflare Pages, Netlify, Vercel, or another static host.

The site is a single self-contained HTML file with responsive CSS and a small JavaScript-generated calibration visualization.
